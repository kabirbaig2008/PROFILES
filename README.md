# Swarm Cursors

An original Chrome Manifest V3 extension that displays a swarm of animated dots around the mouse pointer.

## Install
1. Extract this ZIP.
2. Open `chrome://extensions` in Chrome.
3. Enable **Developer mode**.
4. Select **Load unpacked**.
5. Choose the extracted `swarm-cursors` folder.

## Controls
Use the extension popup to enable/disable the swarm and change cursor count, color, and size.

## Notes
- The extension uses the Chrome Storage API.
- It runs on pages permitted by the content script match pattern.
- Some restricted browser pages (such as `chrome://` pages and the Chrome Web Store) do not allow extensions to inject content scripts.
